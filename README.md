# 주식비서 Android

앱 시작 화면인 시장 요약 홈과 삼성전자 종목 상세 페이지를 구현했습니다.

현재 동작하는 부분:

- 코스피·코스닥·원달러 시장 지표와 투자자 동향
- 오늘의 시장 장중 흐름 예시 차트
- 내 종목·최근 조회 목록과 상세 페이지 이동
- 주요 뉴스 목록
- 거래량·등락률·시가총액 순위 탭
- 종목 기본 정보와 예시 가격 표시
- 3분봉 형태의 임시 미니 차트
- 관심종목 등록/해제 버튼
- 관리종목 주의 안내
- 종목요약, 뉴스·공시, 분석, 기업, 리서치 탭 선택

현재 지수, 가격, 뉴스와 경고 정보는 화면 확인을 위한 예시 데이터입니다. 실제 주가 API와 서버는 다음 개발 단계에서 연결합니다.
